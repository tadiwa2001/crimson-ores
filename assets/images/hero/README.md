# Hero image

Replace `hero-bg.svg` with a high-quality mining-related image (yours, or properly licensed).

## How to replace

1. Add your image here, e.g. `hero.jpg` (recommended: landscape, 1920×1080 or larger, JPG/WebP).
2. In `index.html`, update the hero `<img>`:

   ```html
   <img src="assets/images/hero/hero.jpg" alt="" aria-hidden="true" ...>
   ```

A dark overlay is already applied over the image, so headline text stays readable.
