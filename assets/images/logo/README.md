# Logo

Replace the placeholder logo files in this folder with the real Crimson Ores logo.

Files referenced by the website:

| File | Use |
|------|-----|
| `logo-white.svg` | White/teal logo on dark backgrounds (used in the navbar and footer). |
| `logo-teal.svg`  | Teal/black logo for light backgrounds. |
| `logo-mark.svg`  | The mark only (pickaxes + crystal). |

## How to replace

1. Keep the same filenames to avoid editing any HTML, OR
2. Update the `<img src="...">` references in `index.html` and `projects.html`.

For best results, use **SVG** (crisp at any size) or a transparent **PNG**. Preserve the logo's proportions and don't stretch it — the site sets only the height, so a wide logo will scale down automatically.
